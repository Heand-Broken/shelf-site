# Shelf — privacy policy & landing page

Static site for the **Shelf** browser extension (拾页 Shelf).

- `index.html` — product landing page
- `privacy.html` — privacy policy (中/EN)

This repository is the canonical home of the pages referenced by the extension's
store listings (Chrome Web Store, Edge Add-ons, Firefox AMO, Opera Add-ons).
The privacy policy URL must stay reachable for as long as the extensions are
listed, so it is hosted independently of any single vendor.

Built for GitHub Pages. No build step, no dependencies — plain HTML and CSS.
